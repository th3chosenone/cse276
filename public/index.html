ℹ️ How It Works

Problem: Travelling Salesperson Problem with Time Windows (TSPTW) — find the shortest route visiting every selected delivery house exactly once, departing from and returning to the depot, while respecting each house’s delivery time window.


Score formula: score = distance_px + 1.5 × 60 px/min × minutes_late

Units: distances in pixels; speed = 60 px per minute; time windows in minutes from midnight (540 = 09:00, 1080 = 18:00).


Algorithms implemented:

  • Nearest Neighbour (NN) — greedy construction: always visit the closest unvisited node.
  • Greedy (Cheapest) Insertion — iteratively insert the cheapest unvisited node.
  • 2-opt — local search: reverse segments that reduce total distance.
  • Hill Climbing (HC) — random restart local search accepting any improvement.
  • Simulated Annealing (SA) — probabilistic acceptance of worse moves; temperature decreases each iteration.
  • Exact (Branch & Bound) — guaranteed optimal; limited to ≤12 nodes.

Road routing: routes follow actual map roads using A* pathfinding on the detected road mask (dark pixels). Distance = sum of pixel-length road paths.
